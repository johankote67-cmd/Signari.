# Fuentes de Lengua de Señas Mexicana

Organizar aquí las fuentes y materiales que respalden el contenido educativo.

- `diccionarios/`: diccionarios y repertorios documentados.
- `abecedario/`: materiales sobre configuración manual del alfabeto.
- `gramatica/`: gramática, sintaxis y estructura lingüística.
- `vocabulario/`: vocabulario temático con referencias.
- `investigacion/`: artículos, estudios y notas de validación.

Para cada recurso registrar autor o institución, título, fecha, enlace o referencia, licencia/permiso de uso y fecha de consulta. No publicar materiales protegidos sin autorización. Las señas y explicaciones deben revisarse con personas competentes en LSM y, cuando sea posible, con integrantes de la comunidad sorda.
